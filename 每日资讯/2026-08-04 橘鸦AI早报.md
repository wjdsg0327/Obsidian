## 要闻

### 1. 阿里千问发布 Qwen3.8-Max 正式版，并计划下周开源权重

阿里发布 **Qwen3.8-Max** 正式版，已上线千问 AI 平台 API、Token Plan、Qwen Studio、Qoder 系列等产品。模型基于 Qwen 3.5 架构构建，总参数 **2.4T**、激活参数 **95B**，支持 **100 万上下文**。

- 能力方向：编程、办公、长周期任务、多模态智能体。
- 官方测试：可独立完成约 **16 天**的长程自动编程任务。
- 定价：国内每百万 Tokens 输入 12 元、输出 36 元；海外输入 2 美元、输出 6 美元。
- 开源计划：Qwen3.8-Max 权重预计下周公开，Qwen3.8-27B 也将开放权重。
- 接口生态：兼容 OpenAI 与 Anthropic 接口，可集成到主流智能体框架。

来源链接：见原文 `#1`。

### 2. MiniMax-H3 正式发布权重，ComfyUI 原生支持

MiniMax 正式开源全模态生成系统 **MiniMax-H3**，在 Hugging Face 发布权重，支持文本、图像、音频、视频统一理解，并可生成最高 **2K 分辨率、15 秒、24FPS、32kHz 立体声**视频。

- 已开放权重：H3-Base-FL2VA、H3-Base-Ref2VA 两个任务专用 checkpoint。
- 暂未开源：H3-Context-IR、H3-Regenerate-2K 官方实现，可通过官方 API 接入；H3-Context-IR 提供自建替代流程指导。
- 生态支持：ComfyUI 在权重发布当日已原生支持。
- 许可证限制：禁止美国、欧盟、英国、韩国使用；美国用户可提交正式授权申请。

来源链接：见原文 `#2`。

## 开发生态

### Qoder 一周年：Qwen3.8-Max 全端上线，新老用户可领免费调用

Qoder 宣布 Qwen3.8-Max 上线国际版和中国版全端。8 月 3 日至 9 月 3 日期间，新注册用户和老付费用户可领取 **800 次** Qwen3.8-Max 免费调用，活动期下单可再叠加 **2000 次**，调用有效期至 9 月 30 日。每天 22:00 至次日 08:00（UTC+8）错峰时段享 5 折计费。

### 阿里云百炼 Token Plan 上线 Qwen3.8-Max 正式版

阿里云百炼个人版 Token Plan 已支持 Qwen3.8-Max 正式版；原 Qwen3.8-Max-Preview 将于北京时间 8 月 5 日下线。此前订阅用户可获得一次 7 天额度重置权益。

### Ant Ling 延长 OpenRouter 平台 Ling-3.0-flash 免费期限

Ling-3.0-flash 在 OpenRouter 平台的免费使用期限延长至太平洋时间 8 月 6 日上午 8 点。

### TRAE 为老用户加送积分并推进多项功能升级

TRAE 在积分体系上线后给已升级付费用户按会员档位加送通用积分，未升级速通用户的一次性迁移加赠积分翻倍。官方还表示正在推进生图生视频限额调整、更大上下文窗口、模型思考强度选择、增加 DeepSeek-V4-Flash 正式版模型资源等。

### Kiro 推出统一 Kiro agent harness

Kiro 将此前三个独立代理套件整合为单一 **Kiro agent harness**，已在 Kiro IDE、CLI、Web、iOS 四个客户端上线。新架构作为独立服务器进程运行，通过 **Agent Client Protocol（ACP）** 及扩展与客户端通信；同时引入基于 Cedar 的统一能力级权限模型。

### OpenRouter 发布 Ori Eval

OpenRouter 推出 **Ori Eval** CLI 工具和评估框架，用于帮助开发者为项目选择模型。它可扫描代码库、编写评估文件、运行跨提供商模型比较，并给出量化推荐。运行真实模型评估会产生费用。

### Interconnects AI 上线 Artifacts Hub 与 Adoption Dashboard

Interconnects AI 推出两个免费资源：

- **Artifacts Hub**：整合 OpenRouter 推理 token 数据、Artificial Analysis 模型智能评分、Hugging Face 自定义采用指标，覆盖近两年 792 个模型。
- **Adoption Dashboard**：按地区和组织展示下载量与衍生模型数量，用于观察开源模型生态采用趋势。

### Cloudflare 推出开源 Agent 运行时 @cloudflare/computer

Cloudflare 发布开源 Agent runtime 早期预览版 **@cloudflare/computer**，为每个 Agent 提供独立“计算机”环境，核心是基于 SQLite 的虚拟文件系统，并可按任务动态编排 isolates 与 Linux 容器。官方目标是多数任务使用 isolates，少数任务才启用容器，以优化性能和成本。

### Cloudflare 发布 Billable Usage API

Cloudflare 发布 **Billable Usage API**，面向自助服务账户提供单端点成本与用量查询，覆盖 Workers、R2、D1、Workers AI、Vectorize、Images、Stream 等按量计费产品；字段对齐 FinOps 开放成本与用量规范 FOCUS。目前数据每日更新，企业级合同支持仍在开发中。

## 技术与洞察

### OpenAI 发文详解 GPT-Live 架构

OpenAI 详解第三代语音系统 **GPT-Live**：采用全双工模型，移除传统轮次检测器，支持同时听与说。需要深度推理或调用工具时，可异步调用 GPT-5.5 等前沿模型，同时不中断核心语音流。

工程实现要点：

- 耗时六个月重构系统，将核心媒体流与业务逻辑分离。
- 使用 Go 取代 Python，使新系统 p95 帧流畅度媲美旧系统 p50。
- 开发 WARP 协议与 Instant Connect 技术，将网络启动往返次数从 6 次降至 1 次。
- 支持无缝切换实例与动态上下文压缩。
- GPT-Live 已支持 ChatGPT Voice，包含控制电脑、协调 Agent 等功能；专属 API 即将推出。

### Google Agent Skills 团队分享构建、测试与质量控制机制

Google Agent Skills 团队介绍其 Skill 工程化机制：目标是把 Google Cloud 领域知识编码为结构化开源指令，以减少 AI Agent 幻觉并强制执行最佳实践。

质量控制包括：

- 每个 Skill 使用标准化仓库布局。
- 设计上优先引用远程 MCP 工具。
- 发布前必须通过包含链接检查在内的自动化 CI/CD 管道。
- 提交时和每周进行基于准确性与效率的持续评估。
