## 要闻

### DeepSeek-V4-Flash 正式版 API 上线公测 `#1`

DeepSeek 宣布 DeepSeek-V4-Flash 正式版 API 上线公测。正式版模型 ID 为 `DeepSeek-V4-Flash-0731`，结构和尺寸与预览版保持一致，主要重新进行了后训练。

官方称该模型在多项 Agent 基准中超过 V4-Pro-Preview，并支持 Responses API 格式，针对 Codex 做了适配。此次仅升级 API 端，App 和 Web 端模型未变化，模型权重已在相关平台开放。官方文档还显示，DeepSeek-V4-Pro API 预计 2026 年 8 月初支持接入 Codex。

### 字节跳动 Seed 发布 Seedance 2.5 `#2`

字节跳动 Seed 发布新一代视频生成模型 Seedance 2.5，延续 Seedance 2.0 的多模态音视频联合生成架构，重点加强长叙事、多模态参考和编辑能力。

Seedance 2.5 将单次视频生成时长从 15 秒提升至 30 秒，并支持多轮延长。用户可输入最多 30 张图片、10 段视频和 10 段音频作为参考素材，还能通过时间戳精准编辑音视频内容。模型正在即梦 AI 和豆包专业版陆续上线，API 服务将于近期上线火山方舟。

## 开发生态

### ChatGPT 桌面应用支持点击宠物启动语音模式 `#3`

ChatGPT 桌面应用新增虚拟宠物快捷操作。用户点击桌面端虚拟宠物即可快速打开 ChatGPT Voice，在该入口下检查工作进度，并批准或停止相关任务。

### Google AI Studio 取消独立移动 App `#4`

Google AI Studio 取消独立移动端 App 发布计划。此前该应用在 iOS 和 Android 平台已有超过 80 万次预购。Google 表示将相关能力整合进 Gemini 应用的移动端和桌面端，同时继续优化网页版，以服务更深层次的开发需求。

### GPT-5.4 系列将从 Codex 下线 `#5`

OpenAI 宣布 GPT-5.4 和 GPT-5.4 mini 将于 8 月 31 日从 Codex 中退役，不再向通过 ChatGPT 账号登录的用户提供。这两个模型在 OpenAI API 以及通过 API 密钥验证的 Codex 会话中仍保持可用。

官方建议开发者将 `gpt-5.4` 替换为 `gpt-5.6-terra`，将 `gpt-5.4-mini` 替换为 `gpt-5.6-luna`，并在期限前更新默认设置和自定义任务。

### Nous Research 发布 Hermes Desktop 插件 Kanban `#6`

Nous Research 发布首个官方 Hermes Desktop 插件 Kanban，并同步推出 Desktop Plugin SDK。SDK 模块为 `@hermes/plugin-sdk`，允许开发者为 Hermes Desktop 原生应用添加独立页面、侧边栏导航、快捷键、状态栏操作、主题和后端接口等能力。

## 模型发布

### Qwen-Audio-3.0-ASR-Flash `#7`

千问发布语音识别大模型 Qwen-Audio-3.0-ASR-Flash，目前通过阿里云百炼平台开放调用，提供 Flash、Filetrans 离线文件转写和 Streaming 实时语音识别三个版本。Flash 版本支持最长 5 分钟音频转写。

新模型在上下文一致性、行业词识别、热词定制、语音润色和多语种识别方面升级。官方内部评测称，医疗场景专业词召回率达 95.36%，工业场景达 93.24%，多数场景热词召回率突破 99%，七语种平均语义错误率为 17.09%。Streaming 版本理论出字延迟 300 毫秒，中文工业场景错字率 7.8%。

### LongCat-Flash-Lite-Sparse `#8`

美团在 Hugging Face 发布 LongCat-Flash-Lite-Sparse 模型。该模型是非 thinking 的 MoE 架构，总参数量约 69B，每 token 激活约 3B 参数，引入 LongCat Sparse Attention，原生支持最高 1M tokens 上下文。

官方称，该模型在保持推理和通用知识性能的同时，提升了长上下文推理效率和 Agentic 能力。模型权重以 MIT 许可开源，可通过 SGLang 在单节点部署。

### SenseNova-U1.5-8B-MoT 预览版 `#9`

商汤开源 SenseNova-U1.5-8B-MoT 预览版。该模型基于 NEO-unify 架构构建，是原生统一多模态模型，引入新的 patch 编码层和 ConvDecoder 解码层。

相比前代 U1，预览版支持原生 4K 图像生成，在纹理、材质、光照、真实感、中英文文字渲染和复杂版式组织方面有所提升。图像编辑方面加强了指令遵循、主体身份保持和结构一致性，并支持通过蒙版、边界框和视觉标记进行区域可控编辑。

### K-EXAONE 2.0 `#10`

LG AI 研究院在 Hugging Face 发布 K-EXAONE 2.0。该模型是韩国科技信息通信部主权人工智能基金会模型项目的第二代产品，采用混合注意力 MoE 架构，总参数 7500 亿，激活参数 370 亿。

模型支持多标记预测和 DSpark 两种投机解码方法，可加速生成约 3 至 5 倍，多语言覆盖从六种扩展到十种。该模型采用 Apache 2.0 许可证开源，官方称其长上下文检索和安全性表现优于多款主流开源模型。

### openPangu-2.0-Pro `#11`

华为开源基于昇腾 NPU 训练的大规模混合专家模型 openPangu-2.0-Pro，已提供权重、基础推理代码和技术报告。模型总参数约 5050 亿，激活参数约 180 亿，支持 512K 上下文长度，采用 DSA+SWA 独立分层混合架构与 Muon 优化器。

技术报告披露了 Thinking 和 Non-Thinking 两种模式的测评数据。官方称模型在通用能力和逻辑推理方面表现较好，但也承认在复杂真实软件工程任务上仍与顶尖模型存在明显差距。

## 产品应用

### MiniMax Hub 与 Media Plan `#12`

MiniMax 上线 MiniMax Hub，并面向音视频创作者、影视内容创作团队和内容营销团队推出 Media Plan 订阅方案。MiniMax 称其 API 开放平台目前日均处理超万亿 token 请求，累计服务超 10 万开发者。

Media Plan 覆盖视频生成、图片创作、配乐制作和语音合成等创意场景，提供 Starter、Plus 和 Pro 三个按年订阅层级，支持 Seedance 2.0、MiniMax H3、Seedream 5.0 Pro 等模型。

## 行业动态

### Google Earth AI 生图功能被撤回 `#13`

Google 此前在 Google Earth 中推出 AI 图像生成功能，允许用户用 Nano Banana 2 图像生成模型在卫星地图上创建虚构图像并叠加于真实地图之上。功能上线后，外界担心其可能被用于制造和传播虚假地理信息。

Google 随后表示，观察到用户分享疑似违反平台政策的生成图像截图，因此决定在加强护栏期间回滚该功能。Google 还称生成图像不会在 Google Earth 主界面对其他用户可见，并带有 AI 生成水印。

### 特斯拉中国车机引入豆包语音助手 `#14`

特斯拉中国发布 2026.14.13 版本车机软件更新，分批向 Model 3、Model Y、Model S、Model X 推送，首次在国内车机中引入第三方大模型服务。

豆包大模型智能语音助手可进行自然对话和实时信息检索，提供多款音色以及“万事通”“音乐爱好者”“故事会”等角色，但需要高级车载娱乐服务。官方更新说明显示，该语音助手暂不支持车辆控制指令，不能通过语音调节空调或设置导航。据反馈，该更新适用于搭载 HW 3.0 及更早硬件的车型，即非 AI4 硬件车型。

## 技术与洞察

### GPT-5.6 Sol 与麦克斯韦猜想反例 `#15`

数学家 Philip Arathoon 称，麦克斯韦猜想被证伪，反例由 GPT-5.6 Sol 发现，并由人类数学家整理成论文发布于 arXiv。该反例为由 5 个点电荷构成的三角双锥体结构，产生 24 个平衡点，超过猜想给出的 `(n-1)^2` 上限。

Greg Brockman 转发该消息并称 GPT-5.6 Sol 可解决百年以上数学猜想。也有用户指出，麦克斯韦原文实际表述为 `(n-1)(n-2)` 而不是 `(n-1)^2`，且其本人从未称之为“猜想”，“猜想”这一名称是 2007 年后人提出。目前该发现尚未获得独立验证。
