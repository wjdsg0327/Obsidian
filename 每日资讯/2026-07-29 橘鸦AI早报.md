## 模型发布

### [OpenAI 上线 GPT Live Transcribe 和 GPT Transcribe](https://x.com/OpenAIDevs/status/2082201169443905798) `#1`

OpenAI 在 API 中推出两款语音转文字模型：GPT-Live-Transcribe 面向低延迟实时转录，GPT-Transcribe 面向已完成音频文件与批量任务。新模型据称已取代此前版本，在多口音、多语言、短句、数字与专业术语等真实音频环境中更准确，并可利用输入上下文提升识别质量。

### [Fish Audio 发布 S2.1 Pro 并完成 5200 万美元种子轮融资](https://x.com/FishAudio/status/2082152596739862853) `#2`

Fish Audio 宣布完成 5200 万美元种子轮融资，并发布 S2.1 Pro 语音模型。官方称该模型仅需 5 秒音频即可克隆声音，支持对情绪、语调与节奏进行词级控制，速度比 Cartesia 快两倍，成本为 ElevenLabs 的六分之一。相关链接：[Fish Audio](https://s.fish.audio/tmapke)。

### [微软开源 4B 参数 Mage-VL 和 Mage-Flow 模型](https://github.com/microsoft/Mage) `#3`

微软发布 Mage 模型家族，包含 4B 参数的 Mage-VL 与 Mage-Flow。Mage-VL 面向图像与视频理解，Mage-Flow 面向文生图和指令式图像编辑，支持 512 到 2048 原生分辨率，并提供 Base、RL-aligned、4 步 Turbo 等变体。模型仅限研究用途。相关链接：[Mage-VL](https://huggingface.co/microsoft/Mage-VL)、[Mage-Flow](https://huggingface.co/microsoft/Mage-Flow)。

## 开发生态

### [MCP 发布 2026-07-28 规范：引入无状态核心与多轮往返请求](https://blog.modelcontextprotocol.io/posts/2026-07-28/) `#4`

Model Context Protocol 第五次规范更新将核心协议从双向有状态转为无状态请求响应模型，移除握手和会话 ID，使请求可通过普通负载均衡器路由。新版引入多轮往返请求、基于标头的路由机制、可缓存列表结果，并将授权与 OAuth 2.0 对齐。Tasks 与 MCP Apps 成为版本化扩展框架的一部分，Roots、Sampling 等旧特性被废弃。相关链接：[规范](https://modelcontextprotocol.io/specification/2026-07-28/)、[Claude 适配说明](https://claude.com/blog/bringing-mcp-2026-07-28-to-claude)。

### [OpenAI 开源 Codex Security CLI 与 SDK](https://github.com/openai/codex-security) `#5`

OpenAI 开源 Codex Security 项目，包含命令行工具与 TypeScript SDK，用于发现、验证与修复代码安全漏洞，支持仓库扫描、变更审查、历史发现跟踪和 CI 集成。使用需拥有 Codex Security 访问权限。相关链接：[文档](http://learn.chatgpt.com/docs/security/cli)。

### [火山引擎推出豆包搜索服务](https://mp.weixin.qq.com/s/1nZqQHYqclsIF6__WLscgA) `#6`

豆包搜索服务面向 AI Agent 提供实时、权威、可信的联网搜索能力，输出 Agent 易用的信息格式，并进行信源权威分级治理。支持 API、Skill、MCP 等接入方式，每月提供 500 次免费搜索额度。

### [StepFun 推出 Step Plan 限时免费试用](https://x.com/StepFun_ai/status/2082261411535929354) `#7`

StepFun 面向所有用户开放限时 Step Plan 免费试用，默认获得 15 天 Flash Plan 权限，通过邀请最高可累计 120 天免费访问。活动截至 8 月 24 日 23:59 UTC。

### [Qoder 发布全双工实时语音交互智能体 Qoder Voice](https://mp.weixin.qq.com/s/v8dKt6vdoHvwiVCeLhItAw) `#8`

Qoder Voice 以桌面常驻悬浮气泡形式提供全双工语音 Agent 协作，支持口语指令、插话打断，并可执行代码、操作浏览器与应用。采用 Qwen-Audio-3.0-Realtime 模型，限时免费至 7 月 30 日。

### [Gemini API Managed Agents 更新](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/) `#9`

Google 为 Gemini API Managed Agents 增加模型选择、Environment hooks、预算控制、定时触发器和 Environments API；默认模型变更为 Gemini 3.6 Flash，并向免费层级开放。

### [贾扬清创立 Intent Lab 并发布 fleet](https://x.com/jiayq/status/2082135245776920681) `#10`

Intent Lab 发布自主构建系统 fleet，目标是将模糊意图端到端转化为可维护的生产级软件。早期成果包括 GLM 5.2 TRT-LLM 推理加速、从零构建 SQLite 兼容数据库并通过 600 万项测试、形式化验证的 Agent 文件系统。相关链接：[Intent Lab 博客](https://intentlab.ai/blog/turn-your-intent-into-production-systems)。

### [Cursor 为印度开发者推出 Start 方案](https://cursor.com/blog/cursor-start-india) `#11`

Cursor Start 面向印度用户，定价每月 649 卢比，包含 Grok 4.5、Composer、云端智能体与 iOS 端权限，定位介于免费与 Pro 之间。社区反馈称该方案额度和思考强度可能低于 Pro。相关链接：[讨论](https://linux.do/t/topic/2665954)。

## 技术与洞察

### [Anthropic 利用 Claude Mythos Preview 发现密码学弱点](https://www.anthropic.com/research/discovering-cryptographic-weaknesses) `#14`

Anthropic 前沿红队称使用 Claude Mythos Preview 发现两项密码分析改进：针对后量子签名方案 HAWK 的改进密钥恢复攻击，以及对 7 轮简化 AES 的攻击提速。官方强调这两项不影响现实生产系统。相关链接：[HAWK PDF](https://anthropic.com/document/hawk_key_recovery.pdf)、[AES PDF](https://anthropic.com/document/aes_mobius_bridge.pdf)。

### [Hugging Face 披露自主 AI Agent 入侵事件](https://huggingface.co/blog/agent-intrusion-technical-timeline) `#16`
