## 技术与洞察

### [Andrej Karpathy 称不该再用鹈鹕骑自行车测 LLM](https://x.com/karpathy/status/2083749667410727319) `#4`

Andrej Karpathy 近日发帖称不该再用鹈鹕骑自行车测试 LLM。他使用 Opus 5 进行了一项 3D 世界生成能力测试：向模型输入《指环王》第一段文本，给出约 100 万 token 预算（约 10 美元），要求用 three.js 渲染故事。

Opus 5 运行约 2 小时，写了 5500 行代码，程序化渲染出了故事场景。Karpathy 表示结果虽然粗糙但可运行，LLM 需要在三维坐标系中放置和编排多边形资产并编写动画代码。他同时指出，当前 LLM 在世界和游戏领域仍有弱点，无法高效原生感知视频或在游戏内玩游戏，只能通过缓慢截图来检查工作。

- <https://x.com/karpathy/status/2083749667410727319>

## 模型发布

### [Qwen 等联合发布原生 Computer Use agent Qwen-CUA](https://github.com/xlang-ai/Qwen-CUA) `#5`

Qwen Team 与 XLang Lab 联合发布 Qwen-CUA，一款基于 Qwen 的原生 Computer Use 模型和 agent。Qwen-CUA 仅通过截图感知界面状态，不依赖 DOM 树、辅助功能元数据或任务专用 API，而是通过原生键盘和鼠标事件在浏览器、桌面应用和专业软件中执行操作。

该模型基于 397B-A17B 混合专家架构，在 OSWorld-Verified 基准上取得 86.2 分；更大版本 Qwen-CUA-Max 参数量超过一万亿，在同基准上达到 87.6 分。目前 GitHub 提供了技术报告和参考 demo。

重要链接：

- <https://github.com/xlang-ai/Qwen-CUA>
- <https://x.com/DunjieLu1219/status/2083967342435020889>
