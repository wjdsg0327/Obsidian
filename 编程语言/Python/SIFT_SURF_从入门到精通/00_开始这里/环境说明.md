# 环境说明

## 已验证基线

- Python 3.12.7
- OpenCV 4.12.0
- NumPy 2.2.6
- JupyterLab 4.2.5
- SIFT：可用
- SURF：当前构建不可用（`Non-free algorithms: NO`）

## 推荐方式

本包不主动修改你的全局环境。当前环境能直接运行 SIFT、ORB、AKAZE 和所有几何项目。需要隔离环境时执行：

```powershell
conda env create -f environment.yml
conda activate sift-surf-study
python scripts/check_env.py
```

## SURF 的特殊性

`opencv-contrib-python` 包含许多 contrib 模块，但官方预编译 wheel 通常仍未启用 nonfree 算法。不要用反复重装 pip 包的方法碰运气。需要 SURF 时，按 `03_SURF/SURF_Windows独立编译指南.md` 在单独目录源码编译。
