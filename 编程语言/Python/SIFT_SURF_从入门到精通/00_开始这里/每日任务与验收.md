# 每日任务模板

每次学习都按同一闭环进行：

1. **10 分钟回忆**：不看资料写出上次的三个要点。
2. **25 分钟理解**：读一个小节，自己重画流程或公式关系。
3. **30 分钟实验**：只改变一个变量，保存输入、参数和输出。
4. **15 分钟复盘**：记录成功、失败和下一步假设。

## 三个阶段的硬性验收

- 入门：能运行示例，解释每个输出文件是什么。
- 熟练：能换数据、调参数，并用指标判断改进或退化。
- 精通：能解释算法假设、失败边界、许可与工程成本，并和替代方案对比。
