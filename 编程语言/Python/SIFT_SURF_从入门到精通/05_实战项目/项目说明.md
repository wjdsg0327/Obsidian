# 实战项目说明

## 项目 1：两图特征匹配

命令：

```powershell
python scripts/run_demo.py --algorithm sift --ratio 0.75
```

产物：关键点图、KNN 比率过滤后的匹配图和 JSON 指标。实验任务：改变算法和 ratio，记录匹配数量与可视化变化。

## 项目 2：平面目标定位

```powershell
python scripts/project_planar_localization.py
```

产物：目标在场景中的投影四边形、RANSAC 内点匹配图和指标。验收重点：内点率与投影合理性。

## 项目 3：图像配准/拼接

```powershell
python scripts/project_panorama.py
```

产物：简单拼接结果。该脚本用于理解几何流程，不替代 OpenCV Stitcher 的完整曝光补偿、接缝搜索和融合管线。

## 项目 4：算法性能对比

```powershell
python scripts/benchmark.py --algorithms sift,orb,akaze
```

产物：CSV/JSON 指标和柱状图，对比关键点数、好匹配数、内点数、内点率与耗时。若独立环境启用了 SURF，可把 `surf` 加入列表。

## 自己的数据

所有脚本都允许通过 `--image-a`、`--image-b` 或对应参数换图。先使用本包样例验证环境，再切换自己的图片；这能区分“代码问题”和“数据问题”。
