# OpenCV 官方文档入口

当前网络环境无法保存官方网页副本，因此本目录保留权威入口；中文主线讲义和代码均已离线包含在学习包中。

- SIFT：https://docs.opencv.org/4.x/da/df5/tutorial_py_sift_intro.html
- SURF：https://docs.opencv.org/4.x/df/dd2/tutorial_py_surf_intro.html
- Feature Matching：https://docs.opencv.org/4.x/dc/dc3/tutorial_py_matcher.html
- Homography：https://docs.opencv.org/4.x/d1/de0/tutorial_py_feature_homography.html

网络可用时运行上一级 `下载开放资料.ps1`，即可把这些页面保存到本目录。来源、授权提示和访问日期见根目录 `资源索引.csv` / `资源索引.xlsx`。
