# 资源导读

## 必读一手资料

1. Lowe 2004 SIFT 论文：先看整体流程和实验，再精读尺度空间、定位和描述子。
2. Bay 等 2006 SURF 论文：重点看积分图、Fast-Hessian、方向和 64 维描述子。
3. OpenCV SIFT/SURF 教程：用于把论文概念映射到实际接口。
4. OpenCV 特征匹配和单应性教程：建立从描述子到几何验证的完整链路。

## 阅读方法

- 第一遍只回答：问题是什么、核心方法是什么、如何评价。
- 第二遍给每个符号写中文含义，手画数据流。
- 第三遍把论文步骤映射到 OpenCV 参数和本包脚本。
- 对每个结论问一句：它是在什么数据、硬件和年代背景下得到的？
