# 开放论文入口

- SIFT：David G. Lowe, *Distinctive Image Features from Scale-Invariant Keypoints*  
  https://www.cs.ubc.ca/~lowe/papers/ijcv04.pdf
- SURF：Herbert Bay, Tinne Tuytelaars, Luc Van Gool, *SURF: Speeded Up Robust Features*  
  https://people.ee.ethz.ch/~surf/eccv06.pdf
- SuperPoint：Daniel DeTone, Tomasz Malisiewicz, Andrew Rabinovich, *SuperPoint*  
  https://arxiv.org/pdf/1712.07629

网络可用时，可运行上一级目录的 `下载开放资料.ps1` 保存论文、OpenCV 官方教程和官方样例图。当前离线学习可先使用同目录的 `论文精读指南.pdf` 与各章中文讲义。
