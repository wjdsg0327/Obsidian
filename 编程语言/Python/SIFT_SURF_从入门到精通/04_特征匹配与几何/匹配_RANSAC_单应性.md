# 特征匹配、RANSAC 与单应性

## 1. BFMatcher 与 FLANN

- BFMatcher 穷举比较，行为直观，适合学习和中小规模描述子。
- FLANN 使用近似最近邻索引，常用于大量浮点描述子。
- SIFT/SURF：L2 距离。
- ORB/二进制 AKAZE：Hamming 距离。

## 2. Lowe 比率测试

对每个查询描述子找两个最近邻。只有最近邻显著优于次近邻时才保留：

```python
good = [m for m, n in knn if m.distance < 0.75 * n.distance]
```

比率测试过滤“外观上有多个同样合理候选”的歧义点。

## 3. 交叉验证

交叉验证要求 A 的最佳匹配是 B，同时 B 的最佳匹配也是 A。它和比率测试目标相近但不等价。OpenCV 的 `crossCheck=True` 适合 `match()`；不要和 `knnMatch()` 的比率测试机械叠加而不做实验。

## 4. 单应性矩阵

平面点在两个视图间可用 3x3 单应性矩阵 `H` 联系：

```text
s [x', y', 1]^T = H [x, y, 1]^T
```

H 有 8 个自由度，至少需要 4 对非退化对应点。适合平面目标、文档校正、纯旋转相机全景等场景。

## 5. RANSAC

RANSAC 重复执行：

1. 随机抽取最小样本。
2. 拟合模型。
3. 计算全部匹配的重投影误差。
4. 把误差小于阈值的点计为内点。
5. 保留支持度最高的模型并用内点重估。

## 6. 成功判断

至少同时检查：

- 好匹配数是否达到模型最低要求。
- RANSAC 内点数和内点率。
- 投影四边形是否凸、面积是否合理、是否严重越界。
- 重投影误差分布。
- 运行结果是否在另一组图上仍成立。

匹配线“看起来多”不是验收指标。

## 7. 常见退化

- 四个点近似共线。
- 重复纹理让错误匹配形成伪一致结构。
- 非平面场景和强视差无法被单个 H 解释。
- 运动模糊或滚动快门破坏局部一致性。
- 输入图过小或重叠区域太少。
