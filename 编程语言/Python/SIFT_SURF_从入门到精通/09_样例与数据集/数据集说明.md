# 样例与数据集说明

## 本包样例

`opencv_samples` 中默认提供四张由本包脚本确定性生成的合成图像。`synthetic_object.png` / `synthetic_scene.png` 用于平面目标定位，`synthetic_panorama_a.png` / `synthetic_panorama_b.png` 用于单应性与简单拼接实验。它们不包含个人数据，可重复生成，适合自动验收。

OpenCV 官方 `box` 和 `graf` 样例仍列在资源索引与下载脚本中；网络可用时可下载到同一目录用于替换实验。

## 推荐大型数据集（按需下载）

- Oxford Affine Covariant Features：经典视角、尺度、模糊和光照变化图像对。
- HPatches：局部特征描述与匹配评测常用数据集。
- Aachen Day-Night：更具挑战性的昼夜定位数据。

大型数据集不默认下载。请先看各项目主页的许可和使用条款，再使用 `optional_download_datasets.ps1` 中的入口或手动下载。

## 使用自己的图像

- 保证两图有足够重叠。
- 从近似平面物体开始，例如书封、海报、文档、建筑立面。
- 同时保留一组故意失败的图片，用于学习诊断。
- 不要把包含个人隐私的图片上传到公开数据集或仓库。
