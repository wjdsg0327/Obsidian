# 评估、调优与现代方法

## 指标体系

- 检测耗时、描述耗时、匹配耗时。
- 关键点数量与空间覆盖度。
- 好匹配数、RANSAC 内点数、内点率。
- 重复率（需要已知几何变换或标准数据集）。
- 匹配精确率/召回率（需要真值）。
- 描述子内存、模型/依赖体积和授权成本。

## 公平比较原则

1. 相同输入分辨率和预处理。
2. 固定线程、预热并多次测量，报告中位数或分位数。
3. 不用同一阈值强行比较不同算法。
4. 同时报质量和耗时，不能只报更有利的一项。
5. 记录 OpenCV、Python、CPU、构建选项。

## 典型失败模式

- **弱纹理**：提高灵敏度可能增加噪声点；也可引入边缘/线特征或学习型方法。
- **重复纹理**：更严格比率测试、双向匹配和几何/语义约束。
- **模糊**：关键点和梯度方向都不稳定；提高快门质量通常比调参更有效。
- **强视角/非平面**：单应性模型失效，可使用基础矩阵、PnP、多模型或稠密方法。
- **昼夜/跨模态**：经典梯度描述子可能不足，考虑专门数据与学习型特征。

## 现代替代方案

| 方法 | 主要特点 | 适合场景 |
|---|---|---|
| ORB | 免费、快、二进制描述子 | 实时、移动端、资源受限 |
| AKAZE | 非线性尺度空间，可用二进制描述子 | 速度与质量折中 |
| SIFT | 稳定、区分性强、成熟 | 离线匹配、定位、SfM 前端 |
| SURF | 积分图与 Hessian 近似 | 教学、已有 SURF 工程或特定许可环境 |
| SuperPoint 等 | 学习型检测与描述 | 训练分布匹配、可接受模型依赖 |

## “精通”的判断

精通不等于背下公式，而是能：明确任务假设，选择指标，搭建可复现实验，解释失败，知道何时换模型，并把算法限制转换成工程决策。
