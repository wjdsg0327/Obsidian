# 描述子与距离度量

## 浮点描述子

SIFT 和 SURF 通常输出 `float32` 向量，常用欧氏距离（L2）。

```text
d(a,b) = sqrt(sum_i (a_i - b_i)^2)
```

SIFT 默认 128 维；SURF 常见 64 维，扩展模式为 128 维。

## 二进制描述子

ORB、BRISK、BRIEF 和部分 AKAZE 配置输出比特串，常用 Hamming 距离，即对应位不同的数量。把二进制描述子错误地交给 L2，或把 SIFT 交给 Hamming，都会破坏距离含义。

## 最近邻与比率测试

只选最近邻会在重复纹理中产生大量歧义。Lowe 比率测试比较最近邻 `d1` 与次近邻 `d2`：

```text
d1 < ratio * d2
```

`ratio` 越小越严格。0.7–0.8 是常见起点，但不是普适真理，应结合内点率和召回需求调节。

## 归一化的意义

描述子归一化减弱局部对比度变化。SIFT 还会截断过大的分量后再次归一化，降低少数强梯度的支配作用。
