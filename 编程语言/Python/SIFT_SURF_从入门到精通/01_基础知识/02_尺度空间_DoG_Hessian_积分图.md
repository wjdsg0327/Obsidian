# 尺度空间、DoG、Hessian 与积分图

## 高斯尺度空间

同一个结构在远处可能只有几像素，在近处可能占几十像素。尺度空间用不同标准差的高斯核平滑图像：

```text
L(x, y, sigma) = G(x, y, sigma) * I(x, y)
```

随着 `sigma` 增大，细节被逐步抹去。SIFT 不在单一分辨率上找点，而是在位置和尺度的三维空间中找稳定极值。

## DoG：高斯差分

SIFT 用相邻尺度的高斯图相减：

```text
D(x, y, sigma) = L(x, y, k*sigma) - L(x, y, sigma)
```

DoG 是尺度归一化 LoG 的高效近似。候选点需要和当前尺度、上下相邻尺度共 26 个邻居比较。

## Hessian 与边缘响应

Hessian 矩阵反映局部二阶变化：

```text
H = [[Dxx, Dxy],
     [Dxy, Dyy]]
```

- 两个特征值都大：角点/斑点结构。
- 一个大一个小：边缘，定位沿边缘方向不稳定。
- 都小：平坦区域。

SIFT 用 Hessian 的迹与行列式比例剔除边缘响应；SURF 直接用 Hessian 行列式近似做检测。

## 积分图

积分图 `S(x,y)` 保存从左上角到 `(x,y)` 的像素和。任意轴对齐矩形区域的和可用四次查表得到，计算量几乎不随矩形大小变化。SURF 利用它快速计算大尺度盒式滤波器，这是它早期速度优势的核心来源之一。
