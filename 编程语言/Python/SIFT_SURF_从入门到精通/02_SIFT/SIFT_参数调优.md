# SIFT 参数调优

OpenCV 接口：

```python
cv.SIFT_create(
    nfeatures=0,
    nOctaveLayers=3,
    contrastThreshold=0.04,
    edgeThreshold=10,
    sigma=1.6,
)
```

## 参数解释

| 参数 | 增大后的典型效果 | 使用建议 |
|---|---|---|
| `nfeatures` | 只保留更强的前 N 个；0 表示不按数量限制 | 需要固定预算时设置 |
| `nOctaveLayers` | 尺度采样更密，耗时增加 | 默认 3 通常足够 |
| `contrastThreshold` | 删除更多低响应点 | 噪声大时提高，弱纹理时降低 |
| `edgeThreshold` | 通常保留更多边缘型候选 | 不要误解为越大过滤越强 |
| `sigma` | 初始平滑更强 | 输入已模糊时谨慎增大 |

## 正确调参方法

1. 固定图片和所有其他参数。
2. 每次只改一个参数。
3. 同时记录关键点数、好匹配数、RANSAC 内点数、内点率和耗时。
4. 至少加入一组失败图，不要只在成功样例上优化。

## 不推荐的判断方式

- 只追求关键点最多。
- 只看画出来的连线是否“热闹”。
- 在同一图片对上反复微调后宣称算法更好。
- 忽略图像分辨率、缩放和压缩质量的变化。
